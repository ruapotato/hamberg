Environment Texture Overrides
==============================

PNG files in this directory are auto-generated by TextureGenerator on first run.
You can hand-edit any of these PNGs and the game will load your version instead
of regenerating the texture.

Files generated:
  tree_<type>_front.png  - Tree textures (oak, pine, dead, magic, swamp, cactus,
                           palm, frost_pine, crystal_tree, ember_tree, dark_oak)
  bush.png               - Bush texture
  rock.png               - Rock texture
  grass.png              - Grass texture

To regenerate a texture from scratch, simply delete its PNG file.
